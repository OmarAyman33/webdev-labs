## 1.1 HTML

### different tags and what they do: 

heading tags used to represent hierarchal information:

```html
<h1>, <h2>.... <h6>
```

links:

```html
<a href = "URL here"> display text </a> 
```

images: (self closing)

```html
<img src = "image URL or local path" alt = "alt text" width = img_width height = img_height>
```

line breaks: (self closing)

```html
<br>
```

text styling tags:

```html
<b> bold text </b>
<i> italic text </i>
<del> strikethrough text </del>
```

### tag attributes

style attribute (used for inline CSS):

```html
<body style = "CSS here"> content </body>
```
